# NOTICE

## Upstream origin

This repository is intended as a fork/adaptation of:

- `nanzhipro/Karpathy-llm-wiki-bootstrap-skill`
- https://github.com/nanzhipro/Karpathy-llm-wiki-bootstrap-skill

That repository implements a persistent LLM-maintained Wiki architecture inspired by Andrej Karpathy's
LLM Wiki concept.

The original concept is referenced by the upstream project at:

- https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

## ORTHO-X adaptation

MAIVAN.ai / ORTHO-X adapts the persistent knowledge pattern to longitudinal orthopaedic care, including
clinical provenance, structured assertions, human confirmation, supersession, surgical events,
rehabilitation and outcome linkage.
