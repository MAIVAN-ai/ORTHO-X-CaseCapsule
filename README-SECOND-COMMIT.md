# ORTHO-X Case Capsule — Second Commit Package

This package adds a completely synthetic proximal femur fracture reference Case Capsule to the
`MAIVAN-ai/ORTHO-X-CaseCapsule` repository.

Drop the `examples/` directory into the repository root.

The example demonstrates:

- referral and baseline state;
- imaging evidence;
- provisional and superseding AO/OTA classification assertions;
- treatment mapping;
- synthetic operative fixation;
- DISH-domain surgical-site outcome recording;
- rehabilitation;
- ICHOM-aligned patient-centred / functional outcomes;
- provenance events;
- current-state vs historical-state separation.

No real patient information is included.
